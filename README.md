# AI Minutes Maker

会議の音声ファイルをアップロードするだけで、AI が自動的に文字起こしと議事録を生成する Web アプリケーションです。

---

## 1. アプリ名

**AI Minutes Maker**

---

## 2. アプリ概要

「AI Minutes Maker」は、会議音声から構造化された議事録を自動生成するツールです。

**主な流れ：**
1. 会議の音声ファイル（mp3 / wav / m4a）をアップロード
2. OpenAI の Whisper API で高精度な文字起こしを実行
3. GPT-4o が文脈から誤認識を補正しながら、実務で使える形式の議事録を生成
4. ワンクリックでクリップボードにコピー可能

シンプルな 1 ページの UI で、セットアップから利用まで簡単に始められます。

## 4. 主な機能

| 機能 | 説明 |
|------|------|
| **音声ファイルアップロード** | mp3 / wav / m4a 形式に対応（最大 25MB） |
| **ドラッグ＆ドロップ対応** | ファイルをドラッグ＆ドロップでアップロード可能 |
| **自動文字起こし** | OpenAI Whisper API による高精度な文字起こし（日本語対応） |
| **議事録自動生成** | GPT-4o による構造化された議事録の生成 |
| **誤認識補正** | 音声認識の誤りや表記ゆれを、会議の文脈から自動補正 |
| **コピー機能** | ワンクリックで議事録をクリップボードにコピー |
| **エラーハンドリング** | ファイル未選択・非対応形式・API エラーを適切に通知 |
| **ファイル自動削除** | 処理完了後に音声ファイルをサーバーから即時削除 |

---

## 5. 対応音声形式

- **mp3**
- **wav**
- **m4a**（ffmpeg で自動的に mp3 に変換）

最大ファイルサイズ：**25MB**

## 6. 使用技術

| 層 | 技術 |
|------|------|

## 8. セットアップ方法

### 前提条件

- **Python 3.9 以上**
- **pip**（Python パッケージマネージャー）
- **OpenAI アカウント**と API キー
- **ffmpeg**（m4a 形式対応時に必要）
  - macOS: `brew install ffmpeg`
  - Ubuntu: `sudo apt-get install ffmpeg`

### セットアップ手順

```bash
# 1. リポジトリをクローン
git clone https://github.com/daifukucode-prog/ai-minutes-maker.git
cd ai-minutes-maker

# 2. 仮想環境を作成・有効化
python -m venv venv
source venv/bin/activate   # macOS / Linux

# 3. 依存パッケージをインストール
pip install -r requirements.txt
```

---

## 9. .env の設定方法

### 1. .env ファイルを作成

```bash
cp .env.example .env
```

### 2. OpenAI API キーを設定

テキストエディタで `.env` ファイルを開き、以下を記入：

```
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

## 11. 使い方

1. 音声ファイルをドラッグ＆ドロップまたはクリックで選択
2. 「議事録を生成する」ボタンをクリック
3. 文字起こし結果と議事録が表示される

## 13. 工夫した点

### 1. **実務フォーマットの議事録設計**
- 6 つのセクション で構造化
- 実際のビジネスで使える形式
- 決定事項と ToDo を明確に分離

### 2. **AIの出力形式を固定**
- GPT-4o へのプロンプトで出力フォーマットを厳密に指定
- ユーザーが加工なしで即座に転記可能

### 3. **決定事項とToDoの明確な区別**
- AIに両者の定義と具体例を明示的に指示
- 推測で作業を追加しない仕組み

### 4. **音声認識の誤認識・表記ゆれを自動補正**
- 会議の文脈から AIが自動で誤りを推測して補正
- 例：「AI26アプリ」→「AI議事録アプリ」
- 例：「オープンAPI」→「OpenAI API」

### 5. **MVPとして機能を絞り、短期間で完成**
- 1 ページの UI でシンプル
- m4a 形式は ffmpeg で自動変換
- データベース不要

### 6. **OpenAI API キーを .env で管理**
- `python-dotenv` で環境変数から安全に読み込み
- コードに直接 API キーを書かない設計
- `.gitignore` で `.env` を除外

### 7. **セキュリティ対策**
- ファイル処理完了時に即座に削除
- `secure_filename` でファイル名のサニタイズ
- ファイルサイズ制限（25MB）

### 8. **ユーザー体験の工夫**
- ドラッグ＆ドロップでの直感的なアップロード
- 処理中のローディング表示
- ワンクリックで議事録をコピー
- 区別されたエラーメッセージ

## トラブルシューティング

### API キーエラーが出た場合
- `.env` ファイルが存在し、正しい API キーが入力されているか確認

### ファイルが 25MB を超える場合
- ファイルサイズを 25MB 以下に圧縮

### Whisper API の品質が低い場合
- 音声が明確で、バックグラウンドノイズが少ないことを確認

### m4a ファイルが変換されない場合
- `ffmpeg` がインストールされていることを確認
